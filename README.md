# Beetroot EMB 4

## Опис програми

Цей проєкт для STM32 демонструє та вимірює різницю між копіюванням пам'яті через звичайний `memcpy` і через DMA (режим memory-to-memory).

Після старту програма:

1. Ініціалізує лічильник тактів DWT для точних вимірювань у CPU ticks.
2. Налаштовує callback завершення DMA-трансферу.
3. У циклі запускає бенчмарк:
	 - виділяє буфери `src` і `dst` (по 1024 слова, тобто 4 КБ);
	 - вимірює, скільки тактів CPU блокує `memcpy`;
	 - запускає DMA-копіювання через `HAL_DMA_Start_IT`;
	 - вимірює:
		 - час блокування CPU на виклику DMA;
		 - фактичний час апаратного копіювання до callback завершення.
4. Відправляє результати в USB CDC (віртуальний COM-порт).
5. Перемикає LED на PC13 кожні 2 секунди як індикацію роботи.

## Мета

Показати, що при DMA процесор блокується значно менше під час запуску копіювання, тоді як основна передача даних виконується апаратно.
