# STM32F411 USB CDC UART Bridge

## Опис

Проект реалізує мост між UART і USB CDC на мікроконтролері STM32F411CE (BlackPill board). Програма отримує дані з послідовного порту UART, передає їх через USB Device у вигляді CDC (віртуальний COM-порт) та забезпечує візуальне зворотного зв'язку через LED.

## Основні функції

- **UART прийом**: Неблокуючий прийом даних з USART2 (PA3 RX, PA2 TX)
- **USB CDC**: Передача отриманих даних через USB у вигляді віртуального COM-порту
- **LED індикація**: Блимання LED (PC13) при отриманні кожного байту
- **C++ клас Led**: Об'єктно-орієнтований інтерфейс для управління світлодіодом

## Апаратура

- STM32F411CE (BlackPill)
- LED на GPIO PC13
- USB CDC для комунікації

## Компіляція

```bash
pio run
```
