# Генератор тону на ESP32-S3

Програма без кнопок послідовно генерує синусоїдальні тони від 200 до 3000 Гц
і назад із кроком 200 Гц. Кожен тон триває 1 секунду; після повернення до
200 Гц цикл повторюється.
16-бітний стереосигнал із частотою дискретизації 32 кГц передається на
зовнішній I2S ЦАП або підсилювач:

- BCK: GPIO 15
- WS/LRCK: GPIO 17
- DATA: GPIO 16

З'єднайте землю пристрою із землею ESP32-S3 та подайте живлення відповідно до
його специфікації. Діапазон, крок і тривалість тонів можна змінити в
`src/main.cpp`. Макроконстанти GPIO розташовані на початку того самого файлу.

## Аудіомодуль

Модуль `lib/audio` виводить звук через I2S у режимі master. Конфігурація
`audio_config_t` задає GPIO BCK, WS і DATA, частоту дискретизації, розмір
буфера I2S та функцію генерації семплів. Формат виходу: два канали, 16 біт.
Функція генерації має заповнювати `output[0]` і `output[1]` значеннями від
-1.0 до 1.0.

Викличте `audio_init(config)` один раз у `setup()` і перевірте результат.
Після успішної ініціалізації викликайте `audio_run()` у `loop()`. Модуль
підтримує один екземпляр і повідомляє про помилки через Serial.
Приклад генерації тону наведено в `src/main.cpp`.

Під час збирання PlatformIO встановлює версії AudioTools і Maximilian,
зазначені в `platformio.ini`:

```bash
pio run
pio run -t upload
pio run -t monitor
```
