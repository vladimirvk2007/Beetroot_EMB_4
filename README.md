# Beetroot_EMB_4

Проєкт на PlatformIO для ESP32-S3 (Arduino framework), який реалізує позиційне керування двигуном за допомогою ПІД-регулятора.

## Що робить програма

- Зчитує положення потенціометра (ADC) і перетворює його в кут завдання 0..360 градусів.
- Зчитує кут з інкрементального енкодера (квадратурний режим x4).
- Керує ШІМ виходом двигуна через ПІД-регулятор.
- Утримує максимальне досягнуте значення потенціометра (`hold`), тобто завдання не зменшується, поки потенціометр не повернули майже в нуль.
- Має захист/фіксацію (`latch off`): регулятор вимикається при досягненні межі кута або верхньої межі ADC, і вмикається знову тільки після повернення потенціометра до мінімуму.

## Середовище

- Плата: `esp32-s3-devkitc-1`
- Фреймворк: `arduino`
- Платформа: `espressif32`
- Швидкість Serial Monitor: `115200`

## Основні залежності

- `madhephaestus/ESP32Encoder`
- `br3ttb/PID`

```bash
pio run -t upload
```

5. Відкрити монітор порту:

```bash
pio device monitor -b 115200
```

## Піни (за замовчуванням)

- PWM вихід: GPIO 18
- Енкодер A: GPIO 15
- Енкодер B: GPIO 16
- Потенціометр (ADC): GPIO 4
