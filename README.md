# Beetroot EMB 4

Навчальний проєкт для демонстрації роботи UART та I2C на платі BlackPill зі STM32F411CE.

## Що демонструє проєкт

Прошивка налаштовує I2C1 і раз на секунду зчитує 8 регістрів годинника DS1307 (адреса 0x00–0x07), виводячи їх у hex. UART-модуль містить функції для ініціалізації USART1, приймання та передавання даних. I2C-модуль налаштовує I2C1 у режимі master та надає блокувальні функції передавання, приймання, перевірки пристрою та читання регістрів.

## Конфігурація

- MCU: STM32F411CEUx
- Framework: STM32Cube HAL
- Збірка та завантаження: PlatformIO, ST-Link
- UART: USART1, 115200 baud, 8N1, PA9 (TX), PA10 (RX)
- I2C: I2C1 master, PB6 (SCL), PB7 (SDA), 100 кГц у прикладі (до 400 кГц)

Під'єднайте DS1307: SCL до PB6, SDA до PB7, а також живлення та GND. Увімкнені внутрішні підтягувальні резистори, але для надійної роботи на шині мають бути зовнішні (зазвичай вже є на модулі DS1307). Результат зчитування виводиться через `printf`.

Для I2C створіть `I2C_HandleTypeDef` на стороні застосунку та передайте його в `I2C_Init(&hi2c, I2C1, 100000U)`. Функції модуля приймають 7-бітну адресу пристрою (без зсуву): `I2C_Probe`, `I2C_ReadRegister`, `I2C_Transmit`, `I2C_Receive`. GPIO, тактування та HAL MSP налаштовує сам модуль, окреме налаштування I2C у CubeMX не потрібне.

## Структура

- `Src/app/main_app.cpp` — приклад зчитування регістрів DS1307
- `Src/uart/uart.c` — функції UART-модуля
- `Src/i2c/i2c.c` — функції I2C master і конфігурація I2C1 та GPIO
- `Inc/i2c/i2c.h` — API I2C-модуля
- `Src/main.c` — запуск HAL, системного тактування та периферії
- `Src/stm32f4xx_hal_msp.c` — низькорівневе налаштування іншої периферії
