# Генератор тону на ESP32-S3

Програма без кнопок послідовно генерує синусоїдальні тони від 200 до 3000 Гц
і назад із кроком 200 Гц. Кожен тон триває 1 секунду; після повернення до
200 Гц цикл повторюється.
16-бітний стереосигнал із частотою дискретизації 32 кГц передається на
зовнішній I2S ЦАП або підсилювач:

- **BCK** (Bit Clock): GPIO 15
- **WS/LRCK** (Word Select): GPIO 17
- **DATA** (Serial Data Out): GPIO 16

З'єднайте землю пристрою із землею ESP32-S3 та подайте живлення відповідно до
його специфікації. Діапазон, крок і тривалість тонів можна змінити в
`src/main.cpp`. Макроконстанти GPIO розташовані на початку того самого файлу.

## Аудіомодуль (`lib/audio`)

Модуль виводить звук через I2S у режимі master.

**API:**
- `audio_init(const audio_config_t &config)` — ініціалізація з конфігурацією
- `audio_run()` — обробка наступного буфера звуку

**Конфігурація** `audio_config_t` задає:
- GPIO піни для BCK, WS і DATA
- Частоту дискретизації (Hz)
- Розмір буфера I2S в семплах
- Функцію зворотного виклику для генерування аудіо

**Формат виходу:** два канали, 16 біт на семпл

**Функція генерації** має заповнювати `output[0]` (лівий канал) і `output[1]`
(правий канал) значеннями від -1.0 до 1.0.

**Використання:**
1. Викличте `audio_init(config)` один раз у `setup()`
2. Перевірте результат та логи в Serial Monitor
3. Викликайте `audio_run()` у `loop()` для обробки наступного буфера

**Логування:**
- `Error audio: module already initialized` — спроба подвійної ініціалізації
- `Error audio: invalid configuration` — некоректні параметри
- `Error audio: failed to start I2S` — помилка запуску I2S
- `Error audio: module not initialized` — `audio_run()` викликана до ініціалізації

Приклад генерації тону наведено в `src/main.cpp`.

## Залежності

PlatformIO встановлює версії bibliotek, зазначені в `platformio.ini`:
- **AudioTools** — управління I2S
- **Maximilian** — синтез аудіо

## Компіляція та завантаження

```bash
# Компіляція
pio run

# Завантаження прошивки на пристрій
pio run -t upload

# Монітор серійного порту (логи)
pio run -t monitor

# Компіляція + завантаження + монітор
pio run -t upload && pio run -t monitor
```

## Серійний монітор

Програма виводить статус в Serial Monitor (115200 baud):
```
Starting tone generator...
Generating tones from 200 to 3000 Hz
```

## Налаштування

Змініть в `src/main.cpp`:
- `MIN_FREQUENCY` — мінімальна частота (Hz)
- `MAX_FREQUENCY` — максимальна частота (Hz)
- `FREQUENCY_STEP` — крок змінення частоти (Hz)
- `TONE_DURATION_MS` — тривалість одного тону (ms)
- `SAMPLE_RATE` — частота дискретизації (Hz)

Змініть піни в `#define` макросах на початку `src/main.cpp` за потреби.
