# Beetroot EMB 4

Навчальний проєкт для демонстрації роботи UART на платі BlackPill зі STM32F411CE.

## Що демонструє проєкт

Прошивка налаштовує USART1 і працює як UART-ехо: отриманий байт одразу передається назад. UART-модуль містить функції для ініціалізації інтерфейсу, приймання та передавання даних.

## Конфігурація

- MCU: STM32F411CEUx
- Framework: STM32Cube HAL
- Збірка та завантаження: PlatformIO, ST-Link
- Інтерфейс: USART1, 115200 baud, 8N1
- Контакти: PA9 (TX), PA10 (RX)
- Вбудований світлодіод PC13 блимає при отриманні байта (активний низький рівень)

Під'єднайте UART-адаптер перехресно: RX адаптера до PA9, TX адаптера до PA10, а також з'єднайте GND. Налаштуйте термінал на 115200 baud, 8 біт даних, без парності та 1 стоп-біт. Статус запуску та отримані байти виводяться через USB CDC.

## Структура

- `Src/app/main_app.cpp` — приклад UART-ехо
- `Src/uart/uart.c` — функції UART-модуля
- `Src/main.c` — запуск HAL, системного тактування та периферії
- `Src/stm32f4xx_hal_msp.c` — низькорівневе налаштування периферії
