# Beetroot_EMB_4 - KiCad проєкт

Цей репозиторій містить апаратний KiCad проєкт з назвою `Example` та пов'язані виробничі файли/ресурси.

## Огляд проєкту

- Назва проєкту: `Example`
- Основна схема: `Example.kicad_sch`
- Основна плата: `Example.kicad_pcb`
- Версія KiCad у файлах: 10.0
- Типова директорія виводу Gerber (з налаштувань друку плати): `gerbers/`

## Структура репозиторію

- `Example.kicad_pro` - файл проєкту KiCad
- `Example.kicad_sch` - електрична схема
- `Example.kicad_pcb` - топологія плати
- `fp-lib-table` - таблиця бібліотек футпринтів
- `sym-lib-table` - таблиця бібліотек символів
- `boards/` - додаткові файли, пов'язані з платами
- `Example-backups/` - резервні файли KiCad
- `gerbers/` - згенеровані файли для виробництва
- `scripts/` - допоміжні скрипти проєкту (зараз порожня)
- `YD-ESP32-S3-main/` - зовнішні KiCad-ресурси для модуля YD-ESP32-S3

## Початок роботи

1. Встановіть KiCad 10.x (рекомендовано для сумісності з форматом файлів проєкту).
2. Відкрийте `Example.kicad_pro` у KiCad.
3. Запустіть ERC у редакторі схем.
4. За потреби оновіть PCB зі схеми.
5. Запустіть DRC у редакторі плат.

## Генерація виробничих файлів

1. Відкрийте `Example.kicad_pcb` у редакторі плат.
2. Перейдіть у **File -> Plot**.
3. Переконайтеся, що директорія виводу встановлена на `gerbers/`.
4. Згенеруйте Gerber-файли та файли свердління.
5. Перевірте згенеровані файли у `gerbers/` перед передачею у виробництво.

## Нотатки

- Зберігайте великі згенеровані результати (Gerber, backup) в окремих папках.
- Якщо додаєте скрипти автоматизації, розміщуйте їх у `scripts/` і документуйте використання тут.
