# Beetroot_EMB_4

## Опис

Це навчальний проєкт для ESP32-S3, який демонструє перехід у режим light-sleep та пробудження від двох джерел:

- таймера (10 секунд);
- кнопки на GPIO15 (активний низький рівень).

Програма запускає світлодіод, очікує натискання кнопки, переходить у light-sleep і після пробудження виводить причину wakeup у UART.

## Логіка роботи

1. Ініціалізація LED і кнопки.
2. Налаштування пробудження по GPIO (низький рівень на кнопці).
3. Очікування натискання кнопки.
4. Перед сном активуються:
	- пробудження по таймеру;
	- пробудження по GPIO.
5. Вхід у light-sleep.
6. Після пробудження друкується причина, і цикл повторюється.

## Використані піни

- LED: GPIO16
- Button: GPIO15

## Збірка, прошивка та монітор порту

```bash
pio run -t upload -t monitor
```
