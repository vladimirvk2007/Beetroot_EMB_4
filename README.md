## Опис програми

Цей проєкт для ESP32-S3 реалізує простий UART-мост між:

- USB Serial (UART0, `Serial`) з монітором порту в IDE
- апаратним UART1 (`HardwareSerial uart1(1)`) на зовнішніх пінах

Під час запуску програма:

- ініціалізує `Serial` на швидкості 115200 бод
- ініціалізує `UART1` у режимі `9600, 8N1`
- використовує піни:
	- TX: GPIO17
	- RX: GPIO18

У циклі `loop()` програма:

- читає байти з UART1 і виводить їх у Serial Monitor у HEX-форматі
- читає байти з Serial Monitor і пересилає їх у UART1

Таким чином можна діагностувати або тестувати обмін даними між ПК та зовнішнім UART-пристроєм через ESP32-S3.
