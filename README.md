# Beetroot EMB 4

Навчальний проєкт для STM32F411CE (плата BlackPill), що демонструє лічильний семафор і спільну пам'ять у FreeRTOS.

## Що демонструє проєкт

`ledTx` записує команди у спільну пам'ять, а `ledRx` зчитує їх і керує трьома LED-виходами в циклі:

1. Увімкнути LED1 (PA1), зачекати 1 с.
2. Увімкнути LED2 (PA2), зачекати 1 с.
3. Увімкнути LED3 (PA3), зачекати 1 с.
4. Вимкнути LED3, LED2, LED1 з інтервалом 1 с між командами.

Після вимкнення LED1 таск чекає ще 1 с і повторює цикл.

Під'єднайте кожен пін до анода світлодіода через окремий резистор 330–1000 Ом, катоди — до GND. Вбудований світлодіод PC13 не використовується демонстрацією. Світлодіоди працюють і без USB.

Порти й піни задаються макросами у `Src/app/main_app.cpp`; усі три піни мають належати одному порту. При зміні порту також змініть макрос увімкнення його тактування `LED_GPIO_CLK_ENABLE()`.

## IPC: лічильний семафор і спільна пам'ять

| Об'єкт | Призначення |
|--------|-------------|
| `shared_command` | Спільна структура з номером LED і бажаним станом |
| `command_semaphore` | Лічильний семафор, що підраховує сигнали про запис команди |

### Як працює приклад

1. `main_cpp()` створює семафор через `xSemaphoreCreateCounting(3U, 0U)`: максимальне значення лічильника — 3, початкове — 0.
2. `ledRx` чекає на семафор через `xSemaphoreTake()`. Успішний виклик зменшує лічильник на одиницю.
3. `ledTx` записує команду в `shared_command` і викликає `xSemaphoreGive()`, збільшуючи лічильник на одиницю. Між командами він чекає приблизно 1 с.
4. `ledRx` копіює команду в локальну змінну, перемикає LED та виводить лог, наприклад `[ledRx] LED1 ON`.

Семафор передає сигнали, а не самі дані. Запис і копіювання структури виконуються в коротких критичних секціях, щоб таски не зверталися до неї одночасно.

На відміну від бінарного, лічильний семафор може накопичити до трьох сигналів, але спільна структура містить лише одну команду. Якщо отримувач затримається, нові команди перезапишуть попередні, і отримувач може декілька разів прочитати останню команду. Якщо лічильник уже дорівнює максимуму, `xSemaphoreGive()` повертає `pdFALSE`, і відправник повідомляє про це. Для гарантованої доставки кожної команди потрібна інша схема, наприклад черга.

Пам'ять для семафора й тасків виділяється динамічно з heap FreeRTOS.

## Апаратна конфігурація

- MCU: STM32F411CEUx
- Framework: STM32Cube HAL
- Збірка та завантаження: PlatformIO, ST-Link

## Збірка

```
pio run
pio run -t upload
```

## Структура

- `Src/app/main_app.cpp` — спільна команда, семафор і LED-таски
- `Inc/FreeRTOSConfig.h` — конфігурація FreeRTOS
- `Src/main.c` — ініціалізація та запуск планувальника
