# Опис програми

Це тестова прошивка для мікроконтролера з Arduino-сумісним середовищем (PlatformIO), яка перевіряє роботу зовнішньої EEPROM **AT24C32** по шині I2C.

## Що робить програма

1. Ініціалізує UART (`115200`) для виводу логів.
2. Запускає I2C на пинах:
	- `SDA = GPIO8`
	- `SCL = GPIO9`
3. Виконує сканування I2C-адрес (`0x08` ... `0x77`) і показує знайдені пристрої.
4. Перевіряє підключення EEPROM AT24C32 за адресою `0x50`.
5. У циклі проходить всі сторінки пам'яті (`32 байти на сторінку`):
	- формує тестовий рядок,
	- записує його у поточну сторінку,
	- читає назад,
	- виводить результат у Serial Monitor.
6. Після останньої сторінки переходить знову на першу і повторює тест безкінечно.

## Призначення

Програма потрібна для швидкої перевірки:
- коректності підключення EEPROM;
- працездатності I2C-шини;
- стабільності операцій запису/читання по всьому об'єму пам'яті.

## Очікуваний результат

У Serial Monitor мають з'являтися повідомлення типу:
- знайдені I2C-пристрої;
- `Write` для кожної сторінки;
- `Read` з тим самим вмістом, який щойно записали.

Якщо EEPROM не знайдена, програма виведе помилку з підказкою перевірити підключення.
