# Інтернет-радіо на ESP32-S3

Програма відтворює MP3-потік інтернет-радіостанції через зовнішній I2S ЦАП
або підсилювач:

- BCK: GPIO 15
- WS/LRCK: GPIO 17
- DATA: GPIO 16

З'єднайте землю пристрою із землею ESP32-S3 та подайте живлення відповідно до
його специфікації. Макроконстанти GPIO розташовані на початку `src/main.cpp`.
Перед першим запуском зменште гучність підсилювача.

## Налаштування радіо

1. Скопіюйте `include/radio_config.h.example` у `include/radio_config.h`.
2. Локально вкажіть назву мережі та пароль у `WIFI_SSID` і `WIFI_PASSWORD`.
   ESP32-S3 підтримує Wi-Fi 2,4 ГГц. Файл із паролем ігнорується Git, але
   пароль міститься також у скомпільованій прошивці.
3. За потреби змініть `RADIO_URL` у `src/main.cpp` на прямий HTTP URL потоку MP3
   (не адресу вебсторінки чи плейлиста). За замовчуванням задано надану
   адресу станції.
4. Зберіть і завантажте прошивку; стан підключення виводиться в Serial.

При втраті Wi-Fi або потоку програма намагається підключитися повторно.
Вказана станція використовує HTTP: потік не шифрується і не автентифікується.
AudioTools за замовчуванням також не перевіряє сертифікат HTTPS, якщо сервер
перенаправляє на HTTPS.

## Модуль Wi-Fi

Модуль `lib/wifiConnection` підключається до мережі та повторює спроби при
втраті з'єднання. Викличте `wifiConnection_init(ssid, password)` у `setup()`
та `wifiConnection_run()` у `loop()`; остання функція повертає стан Wi-Fi.
Рядки SSID і пароля мають залишатися доступними під час роботи модуля.

## Радіомодуль

Модуль `lib/radio` керує прийманням MP3-потоку та перепідключенням до
станції. Викличте `radio_init(config)` у `setup()` і передавайте результат
`wifiConnection_run()` у `radio_run()` в `loop()`. Конфігурація містить URL
потоку та налаштування аудіо; рядок URL має залишатися доступним під час
роботи модуля. Приклад використання наведено в `src/main.cpp`.

## Аудіомодуль

Модуль `lib/audio` виводить звук через I2S у режимі master. Конфігурація
`audio_config_t` задає GPIO BCK, WS і DATA, частоту дискретизації, розмір
буфера I2S. Початковий формат виходу: два канали, 16 біт.

Використовуйте `audio_mp3_init(config)` для ініціалізації,
`audio_mp3_write()` для подачі даних і `audio_mp3_reset()` перед новим
потоком. Декодер налаштовує формат I2S за параметрами MP3-потоку. Модуль
повідомляє про помилки через Serial.

Під час збирання PlatformIO встановлює версії AudioTools і libhelix,
зазначені в `platformio.ini`:

```bash
pio run
pio run -t upload
pio run -t monitor
```
